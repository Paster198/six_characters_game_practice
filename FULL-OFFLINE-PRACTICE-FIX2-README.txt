Arcaea 全谱离线练习修订版 fix2（ARM64）

沿用原包包名、版本和签名，可尝试直接覆盖上一测试版；无需清除游戏数据。
原始 APK 和上一份 arcaea-full-offline-practice-arm64-test.apk 保留。
曲库仍为 561 首歌曲、1839 张可玩谱面，原谱面和音乐资源内容不变。

本次针对反馈的修订

1. A/B 预览不再经过原生快门转场。直接构造新暂停场景并替换显示，
   音乐保持暂停；拖动请求合并为最新位置，松手立即提交。
   效果开关、应用、取消和 A/B 循环也使用直接替换；普通暂停菜单的重试不变。
   每次仍重新解析原 AFF，确保倒退预览、取消和天地键转换不会累积修改。

2. 天地键转换改用绝对地址跳转，移除旧实现必须在附近分配内存的限制。
   沿用 Path III 原生转换规则；下隐仍沿用 Path I，两个开关可组合。
   用户的失败提示只能定位到初始化失败，没有设备日志，不能声称已实测定位
   手机上的具体系统调用错误；此修订消除了旧实现的一项设备相关失败条件。

3. 所有实际存在的难度显式设置为无需世界解锁、无需隐藏，避免删除字段后
   反而启用游戏默认的 BYD 隐藏/世界解锁设置。Inscribed 及剧情难度的显示与
   可玩状态改为离线本地路径，Divine Oblivion 正式封面不再使用锁定占位图。

4. Final Verdict、Silent Answer 的本地曲目通过普通开局路径，跳过账号及
   剧情进度门槛。BYD 不再绕去下载缓存/令牌验证；真实谱面和音乐文件的
   存在检查仍保留，缺失难度不会伪装成可玩。

5. Black Fate 选包会初始化歌曲列表，旧代码在此读取被清空的解锁条件并
   直接解引用，导致崩溃。有效本地谱面现在避开该条件对象路径。

6. DIE IN 的 ETR、Aether Crest 的 ETR 还有独立的联动购买检查，会读取空的
   解锁条件。本版另外修复这两条开局路径。用户未明确 DIE IN 的复现难度，
   因此不能把该 ETR 原因等同于所有可能的 DIE IN 崩溃原因。
   DIE IN 的背景、音频和谱面参数已核查；原引擎支持其 FTR 的额外 Arc 参数，
   没有为绕过崩溃而删改这些谱面参数。

验证范围

本版仍未进行 Android 真机验证。构建包含原生指纹与分支校验、宿主回归、
Android ARM64 与 Java 编译、实际 APK 资源/元数据检查、启动配置指纹核对、
签名与 ZIP 对齐检查。设备上的功能效果和上述崩溃是否全部消失需要实测。

保留 0.50–2.50 倍速不变调、半透明练习界面、A/B 循环、流速选项和镜头恢复。
练习或实际预览过的本局不写正式成绩。取消恢复位置与设置，不恢复已丢弃判定。
角色功能没有新增变化；本版仍只确认光、对立的离线选择路径。
