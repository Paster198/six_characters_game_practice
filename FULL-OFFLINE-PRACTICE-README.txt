以原 arcaea.apk 的 7.0.255c 引擎为基础，导入用户提供的 Arcaea Infinity_7.0.1f.apk 资源。
原始 APK、上一练习版和 fix1 均保留。新包可尝试覆盖安装，无需清除数据。

曲目与谱面
整理为 561 首歌曲、1839 张可玩谱面，另保留教程。
其中 PST 551、PRS 551、FTR 560、BYD 68、ETR 109。
包含普通目录外的 9 首附加谱面，放在“离线附加谱面”曲包。
这些附加谱没有原始等级元数据，标题明确标注等级未标注；界面的 0 是显示占位值。

新 APK 的 1840 份非教程 AFF 文件均已覆盖。其中 genocider/3.aff 与 Quon 的 BYD
逐字节相同，且不匹配 GENOCIDER 的音乐，故不生成错误的 GENOCIDER BYD 入口。
LastEternity 的 PST/PRS/FTR 只是原始目录中的空占位，没有对应 AFF，因此不列为可玩谱。
新包没有 Sacrosanct 的完整资源，原包也没有可用完整谱面，本次没有伪造该曲。

保留原曲包分组。原有曲包所有权及个别剧情显示限制在本地曲库中放开，
普通游玩不进入特殊剧情挑战分支，所有可选谱面使用普通练习路径。
两个输入 APK 都缺少的 24 个额外视频/视频音频引用已移除；没有替代或伪造视频。
音乐、谱面和背景仍使用已有真实资源。

练习与预览
进入单曲游玩 → 暂停 → “练习”。
练习面板的填充不透明度降至约 31%–38%，可以更清楚地看到背后谱面；文字保持不透明。
拖动 A、B 滑条，或者点击时间文字输入有效时间时，会跳到对应毫秒预览。
预览期间游戏和音乐保持暂停，原暂停菜单临时隐藏。
快速拖动只保留最新位置，避免连续积压重建请求；松手时提交最后位置。
应用后返回暂停菜单，继续游玩时从 A 前的预备段开始。
取消会恢复打开窗口前的位置和已提交设置。

真实预览需要重建谱面，因此实际预览过的本局始终按练习处理，不写正式成绩或对局日志。
取消预览不会恢复已经丢弃的判定成绩；“结束练习”会从整曲开头重新开始正常游玩。
保留 0.50–2.50 倍速不变调、A/B 循环、Note 流速不变/同步变速，以及镜头拓宽状态恢复。

练习窗口另有“下隐”和“天地键转换”两个独立开关，默认关闭，可同时启用。
下隐沿用 Path I 的原生音符淡出效果；天地键转换沿用 Path III 的谱面构建规则。
切换开关会在当前位置重新生成暂停预览；应用后用于本次练习与 A/B 循环。
取消恢复先前设置，结束练习或切换歌曲后清除；不会更改 APK 中的原始谱面文件。

角色离线选择
已核实原游戏的角色选择窗口具有离线路径，初始角色光/对立可切换并保存到本地。
其他角色不仅需要显示资源，还需要正确初始化的技能和状态对象。
新 APK 的专用角色插件针对另一版引擎，不能直接用于当前引擎；本版未强行移植该插件。
本次没有新增全角色解锁，也未能确认其他角色的完整状态可从本地缓存恢复。

验证范围
这是未进行 Android 真机验证的测试版。
已通过 Android 编译、原生调用指纹、预览请求及时间位置和谱面效果的宿主测试、
完整谱面/音频路径、三个启动配置指纹、APK 签名和 ZIP 对齐检查。
v2/v3 签名有效，证书与原包一致；最终 AndroidManifest 确认没有 INTERNET 权限。
实际设备上的预览速度、声音效果、角色选择及每首谱面显示仍需实机验证。

离线模式继续跳过自动登录和账号引导，APK 不请求 INTERNET 权限。
世界、多人、账号同步、在线商店和剧情视频不作为本包的可用功能。
