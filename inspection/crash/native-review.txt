Regression: offline edition exits before the main menu; preceding practice
edition launches normally. Static native investigation, 2026-10-02.

CONFIRMED STARTUP FAILURE PATH

StartScene::init 0x121de7c constructs a std::function object at 0x121ef90
using vtable 0x1aa26c0. Its RTTI explicitly identifies it as the closure for
cocos2d::ThreadTasks::enqueue<StartScene::init::$_10>. The invocation slot
vtable+0x30 points to 0x13dafd0.

This task reads songs/songlist, songs/packlist and songs/unlocks. Each file
is converted by 0x7caba4 to lowercase MD5 hex, concatenated with itself by
0x984164, then converted by 0x7caba4 once more. In Python:
  H(bytes) = md5((md5(bytes).hexdigest() * 2).encode('ascii')).hexdigest()

The formula was checked against the original APK: all three results match
the respective native expected strings exactly. The offline replacements
fail all three comparisons. Whitespace is included; the checksum must be
calculated from the exact packaged bytes, not parsed/reserialized JSON.

Mismatch branches at 0x13db3fc / 0x13db418 / 0x13db444 / 0x13db460 /
0x13db48c / 0x13db4a8 converge at 0x13db670. That code passes w0=0 and
calls PLT 0x1a5bb20. Its GOT slot 0x1b85f60 has .rela.plt symbol "exit".
This is an intentional exit(0), not a null-pointer dereference or stack
failure. It explains why the existing practice edition, which did not
replace these metadata assets, survives the same startup stage.
