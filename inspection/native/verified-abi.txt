Verified ABI notes for original ARM64 libcocos2dcpp.so in this APK
================================================================
Addresses below are virtual offsets from the shared object's load base.
This binary is stripped; names are inferred from RTTI, vtable roles and inspected
callers. No addresses are intended to support other versions/architectures.

retry(false) reconstructs a new scene. retry(true) additionally copies the
current model time into newScene+0x4b4. The new scene's init consumes +0x4b4:
  0xeb3210 onward: Path IV manager mode 4 -> mode2 skip to challengeTime-3000
  0xeb3250 onward: nonzero +0x4b4 -> mode1 seek
Reusing a judged model for backwards jumps does not restore consumed notes.

offsetTime modes
  mode0: subtract delta from both int64 origins; no audio seek.
  mode1: add delta to start offset, update clock, seek audio.
  mode2: mode1 + skip earlier notes in model.
The skip loop compares note+0x18 <= delta+3000. It handles holds, arcs,
taps and bars through their existing virtual judgment functions; it does not
reconstruct old camera/scene control state. mode2 is valid on a fresh model.
Do not write a negative start offset for A<3000: the existing clock adds its
own -3000 pre-roll whenever the start offset is <=0.

Scene controls / enwiden reconstruction
  parser            0x184b94c
  handler           0x19dc448
  model camera setter 0xa8abf4
  LogicSceneControl vtable 0x1a7daf0, RTTI 0x1b058c0
  Note +0x18 int start time; +0x64 int scene-control type
  Control +0x68 float duration; +0x6c int direction
  Type5 = enwidencamera; type6 = enwidenlanes
  type5 writes model+0x54/+0x58/+0x5c
  type6 writes model+0x68/+0x6c/+0x70
  Model update recomputes camera as
    clamp(direction>=1 ? 1+.5*(time-start)/duration
                       : 1.5-.5*(time-start)/duration, 1, 1.5)
  Lane progress uses clamp(direction>=1 ? (time-start)/duration
                                       : 1-(time-start)/duration, 0, 1).

All-note tree shape, mirrored from 0x9ce670..0x9ceac8
  group pointer -> libc++ tree begin node at +0, end sentinel at +8
  node +0 left, +8 right, +0x10 parent
  node +0x28/+0x30 begin/end of vector<LogicNote*>
  Successor traversal is implemented in native/practice_scene.cpp.
The helper only recognizes the exact LogicSceneControl vtable and types5/6.
It restores the last event at/before the actual post-seek chart time, including
the scale already reached within an in-progress transition. It does not alter
note judgments or general AFF camera events. A synthetic 64-bit ABI test covers
multi-node traversal, forward/backward targets, defaults, and invalid vtable.

Status / limits
  Static ABI findings are supported by the disassembly files in this folder.
  Runtime Android testing has not been performed by this analysis subtask.
  analyze.py's fast ADRP reference scanner may yield false positives because
  it approximates register lifetimes; findings above were checked in disassembly.
